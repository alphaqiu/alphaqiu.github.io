万亿参数、昇腾芯片、50 倍价差：读懂 DeepSeek V4 的三个关键词

4 月 24 日，DeepSeek 在其官网和 HuggingFace 上同步上线了 V4 系列的预览版。这距离 R1 横空出世已经过去 15 个月，距离最初传言的发布窗口（2026 年 2 月）也晚了整整两个月。

但迟到并没有削弱它的冲击力。

1.6 万亿参数，但推理时只用 490 亿

V4 采用了 DeepSeek 一贯坚持的 Mixture-of-Experts（MoE）架构，分为两个版本：V4-Pro（1.6 万亿总参数，约 490 亿活跃参数）和 V4-Flash（2840 亿总参数，更小更快更便宜）。每次推理只激活一小部分专家——这相当于一个「超级智库」，每次只请出最相关的几位专家来回答问题。

这种设计的直接结果是：推理成本被压缩到极致。根据 DeepSeek 官方定价：

  • Flash：输入 $0.28/百万 token，输出 $0.28/百万 token
  • Pro：输出 $3.48/百万 token

作为对比，Claude Opus 4.6 的输出价格是 $15/百万 token，GLM 5.1 是 $4.40，Kimi K2.6 是 $4.00。有 HN 用户估算，即使重度使用约 4000 万 token，在 V4 上也只需 $30-70——相当于 GPT-5.5 两百美元订阅双倍的用量。

V4 还引入了几项新架构特性：

  • Manifold-Constrained Hyper-Connections（mHC）：解决了万亿参数级别 MoE 训练不稳定的老问题
  • Engram 条件记忆：支撑百万 token 上下文窗口，官方称全长度检索准确率 97%
  • Multi-token 预测：批量推理场景可获得 2-3 倍速度提升

此外，V4 实现了端到端确定性的推理内核——相同种子、相同输入，输出完全一致。这在主流大模型中尚属首次。

编程基准：追平 Claude，但差距仍在

HN 上一位研究人员 ozgune 对 V4-Pro Max、Kimi K2.6、Opus 4.6 和 Opus 4.7 做了横向对比，结论非常清晰：

DeepSeek V4-Pro Max shines in competitive coding benchmarks. However, it trails both Opus models on software engineering.

翻译成大白话：做算法题很强，做真实工程任务还有差距。

从具体数据看，V4 在 HumanEval 编码基准上拿到了约 94.2%，追平了 Claude 3.7 的 94.0%，超过了 GPT-5.3 的 91.7%。在 SWE-bench Verified（真实 GitHub Issue 修复测试）上，DeepSeek 内部声称达到 83.7%——高于 Claude Opus 4.5 的公开记录 80.9%，但这个数字目前尚未被第三方独立验证。

值得注意的是，此前 DeepSeek 的 R 系列（R1、R2）专注于推理能力。现在这条线已被整合进 V4——推理不再是单独的模型功能，而是内建能力。这也意味着 V4 不只是 V3 的升级，而是 V3 和 R2 的合体。

另一位在概率论和随机矩阵方向做前沿研究的学者 hodgehog11 分享了他的实际体验：在需要理解未见过论文、构造复杂证明的测试中，DeepSeek V4 Pro 的表现「明显领先除 Gemini Pro 3.1 和 GPT-5.4 之外的所有模型」，证明能力「非常令人印象深刻，有些情况下几乎完整」。

但值得注意的是，V4 目前尚不支持多模态。技术报告中明确写道「We are also working on incorporating multimodal capabilities」——这意味着图像、视频理解能力要等后续版本。此外，HN 社区也有评价认为「DeepSeek 大约落后领先者 2 个月」——这是一个合理的定位，但不再是不可逾越的鸿沟。

华为昇腾：一张被低估的底牌

V4 发布当天，华为确认其搭载昇腾处理器的最新 AI 计算集群可以完整支持 V4 模型。

这不仅仅是兼容性声明。DeepSeek 在发布说明中写道：

受限于高端算力资源容量，Pro 模型当前吞吐量仍然受限。待昇腾 950 部署到生产环境后，预计定价将显著下降。

换言之，V4 的 Pro 版本目前之所以会超时和限流，部分原因是华为新一代芯片还没到位。一旦昇腾 950 上线，推理成本还有进一步下降空间。

Counterpoint 分析师 Wei Sun 指出，V4 能在国产芯片上原生运行「具有重大影响」，有助于北京实现更高的 AI 主权，减少对英伟达的依赖。

市场反应也很直接：中芯国际港股涨 9%，华虹半导体涨 15%；而国内竞争对手 MiniMax 和智谱各跌约 8%。

开源 AI 的新格局

从 R1 到 V4，DeepSeek 的叙事发生了微妙转变。Morningstar 分析师 Ivan Su 指出：R1 时代，DeepSeek 是在挑战美国 AI 的领先地位；而 V4 的定位则直接把其他中国开源模型摆到了竞争对手的位置上。

这不是一个「冲击世界」的故事了——这是一个「国内淘汰赛」的故事。阿里、字节、小米（Mimo V2.5 Pro）、月之暗面（Kimi K2.6）都在近期发布了接近前沿水平的新模型。开源模型的竞赛正在中国内部快速升温。

对开发者而言，好消息是选择变多了，价格持续下探。V4 Flash 版本尤其值得关注——多位 HN 用户反馈它「便宜、高效、极快」，在 agent 工作流中表现突出，虽然首次回答质量不如 Pro，但在多轮迭代中能迅速追上。一位开发者当天就用 Flash 版本跑了一个棘手的 Common Lisp 编程任务：「第一次运行有错误，手动喂回错误信息后，第二次就搞定了，代码质量非常高。」另一位用户表示，Flash 的性价比足以支撑他们每天处理数十亿 token 的 MCP 服务器质量评估——这在此前的价格体系下几乎不可想象。

V4 不完美，但它再次证明了一件事：开源不是廉价的替代品，而是价格体系本身的重写者。
