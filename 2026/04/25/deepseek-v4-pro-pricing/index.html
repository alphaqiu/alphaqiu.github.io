DeepSeek V4 Pro 限时2.5折：性价比核弹，这你受得了么？

事情是这样的。我打开 DeepSeek 的定价页面准备充值时，第一反应是：我看错了吧？

V4 Pro，1.6万亿参数的旗舰模型，输出价格 6元/百万tokens。注意——这不是什么阉割版小模型，而是刚刚在 SWE-bench Verified 上和 Claude Opus 4.6 打成平手、LiveCodeBench 跑出全球最高分的那款。

而它的原价是 24元/百万tokens。

限时2.5折，优惠截至 2026年5月5日 23:59。

这个价格到底有多离谱，我帮你算一笔账。

2.5折之后，性价比直接封神

先说结论：DeepSeek V4 Pro 折扣后的输出价格是 Claude Opus 4.6 的 1.2%，GPT-5.4 的 1.5%。

拿具体数字说话。以下是当前主流旗舰模型的输出价格对比（按百万tokens计）：

  • DeepSeek V4 Pro（折后）：输入 ¥3 / 输出 ¥6（约 $0.87）
  • DeepSeek V4 Pro（原价）：输入 ¥12 / 输出 ¥24（约 $3.48）
  • GPT-5.4：输入 ~$15 / 输出 $60
  • Claude Opus 4.6：输入 $15 / 输出 $75
  • Claude Sonnet 4.6：输入 $3 / 输出 $15

一个真实场景：假设你每天调用 100 万 tokens 输出（做代码生成、文档分析、长文写作），一个月就是 30M 输出。用 DeepSeek V4 Pro 折后价，月开销大约 180元；用 Claude Opus 4.6，月开销 2250美元，折合人民币约 1.5万元。差了83倍。

就算你觉得 Opus 太贵，拿 Sonnet 比——折后 V4 Pro 的输出价格也只有 Sonnet 的 1/17。

这不是”便宜一点”，这是把定价体系炸穿了。

别人涨价的涨价，停售的停售

这波折扣的分量，得放在行业大背景下掂量。

阿里云 Coding Plan 已经买不到了。 Lite版永久停售，Pro版每天9:30限量补货、几分钟抢光。取而代之的 Token Plan，标准坐席 ¥198/月，实际可用请求次数只有老 Coding Plan 的三分之一。按请求次数包月的”自助餐模式”，赔不动了。

智谱 GLM 更是年内三连涨。 2月 Coding Plan 套餐涨30%，3月 GLM-5 Turbo API 涨20%，4月 GLM-5.1 又涨10%。更狠的是，4月30日起老套餐（无周限额版本）直接强制停止自动续订——虽然有2个月新套餐补偿，但加了周限额。调价后，GLM-5.1 在 Coding 场景的缓存命中价格已经逼近 Claude Sonnet 4.6。

百度智能云涨5%-30%，腾讯云年内两次涨价。

整个行业都在往上走，DeepSeek 反手一个2.5折。 这不是促销，这是在涨价潮里扔了一颗深水炸弹，全民百万上下文，这你受得了么？

性能不缩水：SWE-bench 80.6%，LiveCodeBench 全球第一

有人会说：便宜没好货。

但这次真的不适用。DeepSeek V4 Pro 是 1.6T 参数的 MoE 模型（49B 活跃参数），4月24日刚发布，直接打出了这样的成绩单：

  • SWE-bench Verified：80.6% — 和 Claude Opus 4.6 的 80.8% 几乎没差别
  • LiveCodeBench：93.5 — 当前所有模型中的最高分
  • GPQA Diamond：90.1% — 研究生级别的物理和化学推理
  • Codeforces Rating：3206 — 超越绝大多数人类程序员

更关键的是，它还带着 100万tokens 的上下文窗口和 38万tokens 的最大输出长度。2026年，“全民百万上下文”已成定局——DeepSeek V4 全系 1M，Gemini 3 Pro 1M，GPT-5.4 超过 1M，Claude 也在公测 1M。曾经128K就算长的时代，一去不复返了。百万上下文意味着单次对话就能吞下整本《三体》三部曲，或者一次性分析一个完整的中型代码库。

而且，开源。MIT 许可证。权重已经在 Hugging Face 上可以下载。

这波限时优惠，到底意味着什么？

作为一个每天都在和 AI 打交道的开发者，我有三个判断：

第一，对个人开发者和小团队，这是”毕业级”选择。 以前你可能在 GPT-4 和 Claude 之间纠结，一个月 API 费用几百上千。现在 V4 Pro 折后价低到几乎可以忽略成本——一个月的重度使用还不到一杯精品咖啡的钱。不需要再 “省着用” 了，放开手脚去调用。

第二，缓存命中机制进一步放大性价比。 V4 Pro 折后缓存命中价格仅为 ¥0.25/百万tokens，是原价 ¥1 的四分之一。如果你的 prompt 有固定的 system instruction 和 tool schema，实际有效输入价格能压到接近零。

第三，这可能是提前预热。 原价 ¥24/百万tokens 输出，虽然相比竞品依然便宜（大约是 Sonnet 的三分之一），但和现在的折扣价比涨了4倍。结合行业涨价潮来看，DeepSeek 选在这个节点放出2.5折，像是在用价格换市场、抢用户心智——先把人圈进来，再谈长期。所以当你看到这篇文章的时候，离优惠结束可能只剩一周了。

不是没有短板

要说不足，V4 Pro 目前不支持图像输入（纯文本模型），如果你的场景需要多模态能力，GPT-5 或 Gemini 2.5 Pro 是更合适的选择。另外 DeepSeek API 在一些地区的网络延迟和可用性也需要考量。

但对于写代码、做推理、处理长文档、构建 agent 这些核心场景，V4 Pro 折后价可以说是 2026年目前为止最没有悬念的性价比之王。

最后问一句：5月5日之前，你打算充多少？

如果你已经用上了 V4 Pro，欢迎在评论区分享你的实际体验。还在观望的，建议先冲一波——反正这价格，就算后面涨回原价，现在充的余额也够用好一阵了。
